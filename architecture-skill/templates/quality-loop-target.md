
# Quality Target 选择器

不要直接复制一个万能 Target。先根据 `skill-system/core/change-contract.md` 选择类型：

- `targets/diagnosis.md`
- `targets/design.md`
- `targets/oracle-review.md`
- `targets/repair.md`
- `targets/migration.md`
- `targets/revert.md`
- `targets/certification.md`

Skill-only 变更默认禁止 `services/**`、`web/**` 和 `contracts/**`。八轮是上限，不是完成标准；诊断、设计和 Oracle 审查不要求制造源码 Diff。
