# Red baseline: Customer Agent Starter

Date: 2026-08-23

The Harness can author and compose individual declarations, but it has no
validated starter package for a real customer-agent project. There is no single
command that installs a coherent Project declaration, domain Skill contracts,
overall/module/architecture/repair Workflows, composition overlays, and provider
bindings into a target workspace. The examples in architecture documents are
not an executable, package-level contract.
